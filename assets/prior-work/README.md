# Prior work — not event work

Everything in this folder was made **before** this hackathon, at a previous event, for
a predecessor project. It is committed here so the team has it on hand and so its
origin is on the record.

`hackathon-rules.md` is explicit: *"A pre-existing project may not be resubmitted, or
extended and entered as a new hackathon project"* and *"Do not fabricate timestamps or
claim starter code as event work."* This folder exists to keep that line visible.

| File | What it is | Made |
|---|---|---|
| `career-brain-promo.mp4` | 30-second promo for **Career Brain**, a job-search product. 1920×1080, H.264/AAC, 21 MB. | A previous hackathon |

## What this is not

**It is not the two-minute demo video.** That deliverable has to show one complete
interaction inside the Slack thread, recorded from this build, today. This file shows
a different product, a different surface and a different story — a web dashboard for
job search, not an agent in a thread.

## If any of it gets reused

Reused pieces belong in `SUBMISSION.md` under **What we inherited**, named
individually. Candidates, if the team wants them:

- The visual language — Safety Orange on a grey ramp, Inter + JetBrains Mono
- The logo mark
- The relationship-graph and warm-path reasoning, as a concept

The core interaction this project is judged on — the Slack agent reading a thread,
surfacing an opportunity, and writing an approved follow-up into Ambiguous — is new
work and belongs under **What we built during the hackathon**.
